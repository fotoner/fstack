# 작업자 보고: <웨이브>-<기호> <모듈 이름>

1. **작업 위치**: <경로>, 브랜치 <이름>(worktree를 쓴 경우)
2. **만든 파일과 바꾼 파일**: 경로 목록. 소유 경로 밖은 없어야 한다. 있으면 이유를 적는다.
3. **구현한 함수**: 스텁에서 몸체를 채운 목록. `NotImplementedError`가 남은 함수 목록.
4. **실행한 검증과 결과**: 명령, 통과 수와 실패 수, 출력의 핵심 줄. 실행하지 못한 검증은 "미실행"과 이유.
5. **통과 기준 대응**: 지시서의 통과 기준 항목마다 어떤 테스트가 확인하는지.
6. **남은 문제**: 알려진 결함, 미구현, 불확실한 부분.
7. **요청 사항**: 공유 파일이나 다른 모듈에 필요한 변경.
   - 시그니처 변경, 환경 변수 추가, 의존성 추가, 다른 담당자의 테이블 변경.
   - 항목마다 이유와 제안하는 정확한 변경 내용을 적는다.
8. **계약과 다르게 해석한 곳**: 계획과 계약이 모호해서 정한 사항. 오케스트레이터가 정본을 정하는 데 쓴다.
