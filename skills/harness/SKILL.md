# harness

저장소 지침은 지도와 불변식만 담는다. 반복되는 문제는 문장이 아니라 검사로 막는다. 스킬은 쓰는 만큼만 둔다.

## 원칙

- **지침은 지도와 불변식만.** 루트 `AGENTS.md`는 구조 위치, 검증 명령, 불변식(어기면 다치는 것), 경로별 규칙 파일의 목록만 둔다. 약 12KB를 넘기지 않는다. 영역별 규칙은 경로별 파일(예: `.claude/rules/<영역>.md`, 하위 폴더의 `AGENTS.md`)로 나눈다. `CLAUDE.md`는 `@AGENTS.md` 한 줄(또는 symlink)로 둔다.
- **반복된 규칙은 검사로.** 같은 교정이 두 번 나오면 lint·훅·스크립트로 옮기고, 지침에는 "어느 검사가 강제하는가"를 적는다(`lesson` 강제 수단 순위).
- **막기보다 되돌릴 수 있게(C9).** 안전은 백업·되돌리기·전후 지문·경고로 만들고, 사람 확인은 한 번으로 줄인다.
- **사용자 하네스와 팀 하네스를 구분한다.** 남이 만든 저장소 지침·훅·스킬은 사용자가 그 저장소를 명시해야 고친다.

## 절차

1. **현황**: 지금 지침 파일·스킬·훅·검사 스크립트·CI의 목록과 크기, 최근 교정 기록(메모리·`~/dev/fstack/local/lessons.md`·세션 로그)을 읽는다. 기존 장치를 고치는 것을 새로 만드는 것보다 먼저 고른다.
2. **위험 자원**: 에이전트가 실수로 건드리면 되돌릴 수 없는 것을 나열한다(실사용 DB, 실물 장치, 사용자 데이터 폴더, 운영 계정, 공개 저장소에 올라가면 안 되는 것). 쓰기 입구를 하나로 모으고, 라이브 경로를 기본 인자로 두지 않고, 시험 기본 경로를 임시 폴더로 둔다. 검사 스크립트가 전후 지문(해시·수정 시각)을 비교해 실물 변화가 있으면 다른 종료 코드로 멈추게 한다. 이름·패턴 kill 같은 금지는 훅으로 막는다(H1·H2).
3. **검사 단계**: 빠른 검사(시험 하나), 변경분 검사(작업 끝, 예: `--changed`), 전체 검사(릴리스) 세 단계를 둔다. 첫 주에 검사 시간을 재고, 느리면 원인(픽스처 비용 등)부터 고친다.
4. **작업 단위**: 이슈 컨벤션(제목, 라벨: 종류·영역·우선순위, 본문 섹션)을 한 번 정한다. 계획·조사 메모는 저장소에 커밋하지 않고 이슈로 둔다. 이슈마다 브랜치·작업 위치를 정하는 규칙과 끝난 worktree 정리를 완료 정의에 넣는다. `~/dev/fstack/local/routing.md` 4절 저장소별 규칙 표에 한 행을 더한다.
5. **보고 틀과 증거 위치**: 작업자 보고 형식(바꾼 것 / 확인한 것: 명령과 수치 / 남은 것, 한국어)을 저장소 스킬이나 지침에 고정한다. 증거가 남는 곳을 하나로 정한다(PR 본문 또는 이슈 닫기 댓글). PR·이슈 템플릿이 있으면 필수 헤딩을 CI나 훅으로 검사한다(검사 없는 PR 템플릿은 65%만 지켜졌고 점점 어긋났다). 리뷰어(봇·모델) 지시는 사람이 읽는 같은 규칙 문서를 가리키게 해서 사본을 두지 않는다.
   - Codex처럼 `AGENTS.md`만 읽는 하네스가 있으므로 안전 불변식은 `AGENTS.md` 안에서 완결한다. 경로별 규칙 파일·훅은 보조다.
   - 에이전트 저작 표기(커밋 trailer, PR 본문 줄)는 하네스마다 다르게 남는다. 공통 규칙은 `AGENTS.md`에 둔다.
6. **공개 저장소 위생**: 사람 이름, 개인 경로, 민감한 조사 내용, 법무 내용이 이슈·커밋·문서에 올라가지 않게 규칙과 pre-push 스캔을 둔다.
7. **크기 예산**: 에이전트에게 항상 실리는 텍스트(루트 지침, CORE, 스킬 설명)의 크기를 재고 예산을 정한다. fstack은 `~/dev/fstack/tools/check_fstack.py`가 잰다. 예산을 늘리려면 이유를 적는다.
8. **확인**: 바꾼 하네스로 실제 작업 하나(작은 이슈)를 처음부터 끝까지 돌려 본다(smoke). 결과와 남은 마찰을 보고한다. 변경은 `ship`으로 올린다.

## 줄이기 (스킬 다이어트)

1. 스킬·규칙마다 호출 기록(세션 로그의 Skill 호출, `SKILL.md` 읽기, `$이름` 언급)을 센다.
2. 0회인 것, 다른 것과 겹치는 것, 자동으로 잘못 켜지는 것을 표로 만든다.
3. 지우거나 합치는 안을 내고, 승인 후 지운다(지운 것은 백업 위치를 적는다). 자동 발동이 문제면 명시 호출로만 켜지게 바꾼다.
4. 지침 크기의 전후 수치를 보고한다.
