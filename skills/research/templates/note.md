# <갈래 제목: 질문 묶음을 한 문장으로>

> 기준일 YYYY-MM-DD. 모든 페이지는 이 날짜의 세션에서 조회했다.
> 확인 방법 표기: `[원문]` 원문 직접 읽음 / `[요약]` 요약기를 거쳐 읽음 / `[스니펫]` 검색 요약만 봄 / `[실행]` 직접 실행해 확인.
> 요약기를 거치는 도구는 따옴표 안의 문장이 원문과 글자 단위로 같다고 보장하지 않는다.
> 하지 않은 것: 로그인, 가입, 결제, CAPTCHA 우회, 비공식 스크래퍼 사용.
> 사용량: 검색 N회 / 열람 M회 (예산: 검색 X회, 열람 Y회)

## Q1. <질문 1>

### Takeaway
결론을 한두 문장으로 쓴다. 이 절만 읽어도 결정에 쓸 수 있어야 한다.

### Cited Findings
- 사실 하나를 한 문장으로 쓴다. 수치와 날짜를 포함한다. (출처: [출처 이름](https://example.com/page), [원문], 확인 YYYY-MM-DD)
- "원문 인용(외국어 그대로)"과 한국어 설명을 함께 쓴다. (출처: [출처 이름](https://example.com/page2), [요약], 확인 YYYY-MM-DD)
- 검색 결과 요약에서만 본 내용은 [스니펫]으로 표기하고, 결정 근거로 쓰지 않는다. (출처: [출처 이름](https://example.com/page3), [스니펫], 확인 YYYY-MM-DD)

### Inferences
- 추론 문장. 근거가 된 사실을 지목한다(예: 위 두 번째 항목에서 이어지는 추론). 추론이라는 점이 문장에서 드러나야 한다.

### Gaps
- 확인하지 못한 것과 이유(접근 불가, 한도, 공식 문서 없음).
- 출처끼리 충돌한 내용: 어느 쪽을 택했고 이유는 무엇인지. 공식 문서를 우선한다.
- 구현 전에 직접 확인해야 하는 항목.
