# setup

환경 작업은 호스트 확인 → 백업 → 실행 → 실제 호출 검증의 순서를 따른다. 사람에게 넘기기 전에 다른 길을 찾는다. 사용자가 정한 삭제 범위를 줄이지 않는다.

## 설치·설정

1. **호스트 확인(C18)**: `hostname`, OS, 셸, 대상 서비스 버전, 관련 저장소의 `git remote -v`를 확인한다. 현재 호스트가 ROUTING 3절의 호스트 표와 다르면 맞는 호스트로 옮긴다. 원격으로 위임해도 된다.
2. **현재 상태 기록**: 버전, 서비스 상태, 설정 파일 위치, 데이터 디렉터리를 기록한다. 바꿀 파일은 `<파일>.bak-<YYYYMMDD>`로 백업한다.
3. **롤백 계획 한 줄**: 무엇을 되돌리면 원래대로 돌아오는지와 판단 시한을 적는다.
4. **변경**: 설치하거나 설정한다. 비밀값은 `request_secret`이나 파일로 받는다(C19). 설정 파일의 내용을 출력하지 않는다.
5. **사람 단계**: 로그인·기기 코드·OAuth·브라우저 승인은 사람 몫이다. 무엇을, 어디서, 언제까지(만료 시각) 하면 되는지 한 번에 적고 기다린다. 기다리는 동안 할 수 있는 다른 단계는 먼저 한다. "완료"를 받으면 바로 이어간다(C5).
6. **검증**: "로그인됨"이 아니라 그 인증으로 실제 API를 한 번 호출하거나 명령을 실행한 결과로 확인한다. CLI는 새 로그인 셸(`bash -lc 'command -v <cmd>'`)에서 확인한다(`verify`).
7. **재시작**: 지금 대화를 실행 중인 서버(T3 등)는 턴 안에서 재시작하지 않는다(H3). 그 호스트의 전용 업데이트 유닛처럼 턴이 끝난 뒤 실행을 보장하는 경로가 있으면 그 경로를 쓰고 없으면 재시작 명령 한 줄을 사용자에게 넘긴다. 고정 지연 타이머는 턴 종료를 보장하지 않으므로 쓰지 않는다. 재시작한 뒤 점검할 포트, 바인드 주소, 관련 예약 작업을 적고 다음 턴에 확인한다.
8. **기록**: 원인과 확인 순서가 다시 쓸모 있으면 `lesson`이나 `wrap`으로 남긴다.

## 장애 대응

1. 증상을 재현하거나 증상이 난 시각과 로그를 기록해 둔다.
2. 같은 장애가 두 번째면 이전 기록(메모리·브레인)의 확인 순서를 먼저 따른다.
3. 로그·상태를 읽고 가설을 2~3개로 줄인다. 가설마다 확인 명령을 하나씩 돌린다.
4. 조치 후보만 나열하고 멈추지 않는다. 되돌릴 수 있는 조치(재시작 예약, 설정 백업 후 수정, 캐시 정리)는 진행하고 보고한다. 되돌리기 어려운 조치(데이터 삭제, 버전 고정 해제, 방화벽 변경)만 묻는다(C8).
5. 고친 뒤 원인과 확인 순서, 재발 감시 방법을 남긴다.

## 정리 (삭제·제거)

1. **범위를 한 번에 확정한다.** 시작할 때 사용자 말에서 범위를 읽는다. 프로그램만인지 설정·계정·캐시까지인지, 백업 후보를 어떻게 할지, 휴지통을 거칠지를 본다. 사용자가 "싹", "전부"라고 했으면 그것이 기본값이고 임의로 줄이지 않는다(C9). 사용자 말에서 읽어 낼 수 없는 것만 한 번 묻는다.
2. **스캔과 목록**: 대상별 크기, 최근 사용, 호출 이력을 읽기 전용으로 모아 표로 보여 준다. 이미 지운 항목, 지금 쓰는 항목, 다른 계정이나 다른 프로젝트의 자료가 섞인 항목을 표시한다(H4).
3. **승인 후 삭제**: 사용자가 승인한 항목만 지운다. 휴지통을 거치지 않거나 자격 증명·레지스트리를 지우는 것처럼 되돌릴 수 없는 삭제는 한 줄로 알린다.
4. **권한이 부족하면**: 관리자 권한이 필요한 일은 권한 상승을 스스로 요청하고 실행 로그를 저장하는 스크립트로 만든다. Windows에서는 UAC 자기 상승을 쓴다. 실행 직후 로그를 읽어 실패 항목을 보고한다.
5. **잔여 확인**: 지운 뒤 다시 스캔해 남거나 다시 생긴 항목을 보고하고 일부러 남긴 것과 이유를 따로 적는다.

## 하지 않는 것

- 샌드박스·권한 오류 하나로 사용자에게 명령을 넘기지 않는다. 다른 권한·다른 호스트·다른 경로를 먼저 시도한다(C10).
- 자동으로 `sudo`를 쓰지 않는다. 비밀번호 없이 sudo를 쓸 수 있더라도 시스템 전역 변경은 한 줄로 알린 뒤에 실행한다.
- 즉시 하라는 업데이트를 임의로 다른 시각에 예약하지 않는다. 즉시 하면 대화가 끊기는 경우에만 위 7단계 경로로 넘기고 그 이유를 적는다.
